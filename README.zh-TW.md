# ClickBook

> **一鍵儲存分頁，讓 AI 自動將其分類至資料夾中。**

ClickBook 是一款基於 Chrome Manifest V3 建構的書籤管理工具。它可以讓您只需點擊一下即可立即儲存當前分頁，並使用 Chrome 內建 AI (Gemini Nano) 或備用規則系統自動將其歸類到適當的資料夾中。

## 螢幕截圖

| 彈出視窗 | 管理儀表板 |
|---|---|
| 點擊圖示一鍵儲存 | 在專用分頁中進行階層式管理 |

---

## 主要功能

| # | 功能 | 描述 |
|---|---|---|
| 1 | **一鍵儲存** | 點擊擴充功能圖示即可立即儲存目前分頁。 |
| 2 | **AI 自動分類** | 使用 Chrome Gemini Nano (`window.ai`) 分析網址與標題並歸類至資料夾。 |
| 3 | **AI 批次整理** | 側邊欄一鍵按鈕，可重新分類所有已儲存的書籤（具備自動備份功能）。 |
| 4 | **自動標籤** | AI 會在背景自動為未標籤的書籤生成並儲存標籤。 |
| 5 | **任務控制中心** | 即時監控所有背景 AI 任務的進度條與狀態。 |
| 6 | **AI 標籤雲** | 可折疊的互動式 HSL 標籤雲，支援篩選、合併與內聯編輯標籤。 |
| 7 | **階層式資料夾** | 支援無限層級嵌套、重新命名、移動與設定 Emoji 圖示。 |
| 8 | **拖放操作 (Drag & Drop)** | 直覺地重新排列書籤與資料夾。 |
| 9 | **模式快照** | 將整個資料夾與書籤佈局儲存為快照並隨時還原。 |
| 10 | **Chrome 同步** | 匯入、匯出並與原生 Chrome 書籤同步。 |
| 11 | **視覺主題** | 支援深色與淺色模式（Dark/Light Mode）。 |
| 12 | **100% 離線** | 完全在本地使用 `chrome.storage.local` 運作（無需外部伺服器）。 |
| 13 | **多語言支援** | 完整支援 7 種語言（英文、韓文、日文、德文、西班牙文、繁體中文、簡體中文）。 |
| 14 | **AI 螢光筆剪藏 (Premium)** | 選取文字並透過右鍵選單自動將其整理為多語言筆記。 |
| 15 | **智慧分頁暫停 (Premium)** | 自動暫停背景不活躍分頁，最多可節省 90% RAM 記憶體。 |
| 16 | **分頁組同步 (Premium)** | 備份並還原 Chrome 原生分頁組至資料夾中。 |
| 17 | **隱私會話清除 (Premium)** | 關閉安全資料夾中的分頁時自動清除 Cookie 與快取。 |
| 18 | **FTS 全文檢索 (Premium)** | 支援即時對已儲存網頁的完整內文進行多關鍵字搜尋。 |
| 19 | **離線閱讀與 Zen 模式 (Premium)** | 無干擾閱讀模式，配備主題、動態目錄與滾動進度條。 |
| 20 | **AI 清理器** | 基於 AI 的重複項檢測，輕鬆清理重複書籤。 |
| 21 | **視覺化心智圖 (Premium)** | 節點式互動心智圖檢視，支援 AI 拓展節點與圖示選擇器。 |
| 22 | **趨勢排行榜** | 內建 GitHub Trending、Hugging Face、Hacker News 及 Wikipedia 排行榜。 |
| 23 | **生產力看板** | 整合 Kanban 風格的 TODO 看板與備忘錄管理系統。 |
| 24 | **智慧行事曆整合 (Premium)** | 無縫整合 Todo/Memo 與多國節假日同步的智慧行事曆。 |
| 25 | **復古彈簧筆記 (Premium)** | 基於 Tiptap 的富文本筆記空間，具備模擬書籍視覺主題。 |
| 26 | **ClickBook 桌面夥伴與專注計時器 (Premium)** | 互動式桌面寵物，配備番茄鐘計時器與環形選單。 |
| 27 | **智慧聲母搜尋** | 超高速韓文聲母搜尋支援（例如 輸入 'ㅋㄹㅂ' 搜尋 'ClickBook'）。 |
