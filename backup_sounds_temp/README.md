# 타이머 완료 및 휴식 테마용 사운드 관리 가이드

이 폴더(`public/buddies/timer-themes/sounds/`)는 집중 타이머가 끝난 후 표시되는 각 효과 테마에 맞는 배경음 및 ASMR 백그라운드 오디오 파일들을 한데 모아 관리하는 공간입니다.

오디오 파일을 아래 가이드라인에 맞춰 해당 파일명으로 넣어주시면 빌드 시 자동으로 패키징에 포함되어 연동됩니다.

---

| 테마 ID | 추천 오디오 파일명 | 연출 분위기 및 어울리는 소리 |
| :--- | :--- | :--- |

## 🛠️ 오디오 에셋 권장 사양

- **파일 포맷**: `.mp3` (브라우저 간 호환성이 가장 높으며 용량 관리에 최적화됨)
- **오디오 포맷**: 44.1kHz, 스테레오(Stereo) 채널
- **비트레이트**: `128kbps` 또는 `192kbps` (확장 크기 절약을 위해 너무 높은 음질보다는 경량 압축 권장)
- **반복 재생(Loop)**: 타이머 오버레이 휴식 시간 동안 계속 재생되므로, **시작과 끝이 부드럽게 이어지는 루프형(Seamless Loop) 음원**을 사용하는 것이 가장 좋습니다.
- **볼륨**: 백그라운드 소음으로 깔리는 사운드이므로, 마스터 볼륨 자체가 너무 튀지 않는 차분하고 잔잔한 데시벨의 음원을 권장합니다. (코드상에서도 기본적으로 마스터 볼륨 볼스터가 적용됩니다.)

---

## 💡 유의 사항

- 파일이 존재하지 않는 경우(예: 사용자가 커스텀 오디오 파일을 아직 복사해 넣지 않은 상태), 타이머 오버레이는 오류로 멈추지 않고 **묵음(Mute) 상태**로 정상 실행되도록 안전하게 예외 처리가 적용되어 있습니다.
- 오디오 파일을 추가한 뒤 크롬 확장 프로그램이 정상적으로 이 파일을 불러오기 위해서는 프로젝트 빌드(`npm run build`)를 수행하여 `dist/` 폴더로 리소스가 복사되도록 해야 합니다.
