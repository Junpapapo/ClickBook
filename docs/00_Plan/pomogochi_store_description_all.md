## ⌨️ 2. 브라우저 단축키 구성 (Commands)

- **`Alt+Shift+P`**: 플로팅 버디 표시 / 숨김 토글 (`cmdToggleBuddy`)
- **`Alt+Shift+T`**: 뽀모도로 타이머 시작 / 일시정지 (`cmdToggleTimer`)
- **`Alt+Shift+M`**: 퀵 메모 / 투두 패널 열기 (`cmdQuickMemo`)
- **`Alt+Shift+S`**: Two-Beat Thinking™ 사고 정리 스프린트 열기 (`cmdThinkingSprint`)
