🚀 ClickBook AI - AI 북마크 & 태스크 매니저

웹 정보와 일상의 실행 사이의 간극을 메웁니다.
ClickBook AI는 Chrome Manifest V3 기반의 로컬 퍼스트 듀얼파워 생산성 허브입니다. 온디바이스 AI(Gemini Nano)를 활용해 저장한 북마크와 일상 태스크를 하나의 인텔리전트 워크스페이스로 통합하고, 모든 데이터를 완전히 내 기기 안에서 처리합니다.

1클릭으로 탭을 저장하고, AI가 자동으로 정리하며, 웹 리소스를 통합 칸반 보드와 스마트 캘린더의 실행 가능한 TODO로 즉시 전환하세요.

🌟 통합 워크스페이스 기능

1. 스마트 AI 북마크 정리 (프라이빗 & 로컬)
- 온디바이스 AI 분류: Gemini Nano(window.ai)를 활용해 URL과 제목을 즉시 분석하고, 8개의 스마트 기본 폴더로 자동 분류합니다.
- AI 일괄 재분류 & 백업: 버튼 한 번으로 전체 라이브러리를 재분류. 자동 백업 시스템이 컬렉션을 항상 깔끔하게 유지합니다.
- 자동 태그 & 태그 클라우드: 문맥 기반 태그를 자동으로 생성하고, 인터랙티브 HSL 컬러 태그 클라우드로 관리합니다.
- 하이브리드 폴백 시스템: Gemini Nano를 사용할 수 없는 환경에서도 스마트 도메인/키워드 패턴 매칭으로 즉시 전환되어 중단 없이 동작합니다.

2. 고급 태스크 & 캘린더 관리 (실행 허브)
- 스마트 Todo 캘린더: 월/주/일 뷰 전환을 지원하는 본격 통합 캘린더. 드래그 앤 드롭으로 일정을 조정하고, 다양한 반복 일정을 설정하며, 한국·미국·일본 등의 공식 공휴일을 자동으로 동기화합니다.
- 칸반 생산성 보드: 태스크와 메모를 시각적으로 관리. 브라우저 배지와 시스템 알림으로 마감일을 추적합니다.
- AI 태스크 컨트롤 센터: 백그라운드 AI 정리 및 자동 태그 작업을 실시간 진행 바로 모니터링. 동시 1개 태스크 제한(컨커런시 가드)으로 브라우저 성능을 안정적으로 보호합니다.

3. ClickBook 버디 & 포커스 모드 (Premium)
- 애니메이션 데스크 펫: 귀여운 애니메이션 캐릭터가 모든 웹 페이지 위에 상주하여, 언제 어디서나 바로 접근 가능. 작업을 방해하지 않습니다.
- 9가지 원형 다이얼 메뉴: 버디를 클릭하면 9가지 빠른 기능이 담긴 원형 메뉴가 즉시 나타납니다:
  * 번역 — 페이지에서 드래그한 텍스트를 즉시 번역.
  * 북마크 — 현재 페이지를 ClickBook에 1클릭으로 저장.
  * AI 대화 — Gemini Nano 챗 패널을 실시간으로 열기.
  * 타이머 — 뽀모도로 집중 타이머를 수 초 안에 시작.
  * 휴식 — 비주얼과 앰비언트 사운드가 결합된 전체화면 힐링 휴식 모드 실행.
  * 메모 — 현재 페이지에 스티키 메모 부착.
  * 할 일 — 오늘의 체크리스트를 빠르게 추가·관리.
  * 버디 숨기기 — 현재 도메인에서 버디를 즉시 숨김. (팝업 또는 우클릭으로 언제든 재표시 가능)
  * 버디 설정 — 크기, 투명도, 애니메이션 속도, 시계 표시 등을 커스터마이징.
- 뽀모도로 집중 타이머: 집중할 시간을 분 단위로 설정하고, 곧바로 깊은 집중 상태로 진입.
- 버디 도감: 베이직, 프리미엄, 히든 등급의 전체 캐릭터를 한눈에 확인하고, 집중 달성 기록으로 잠금 해제.
- 몰입형 완료 테마: 집중 세션이 끝날 때마다 웅장한 전체화면 비주얼 이펙트로 보상 — 오로라 별밤, 고요한 전나무 숲, 타오르는 벽난로, 노을빛 호숫가, 싱잉볼 합성음이 흐르는 명상 요가, 그리고 18편의 시네마틱 켄 번즈 성공 스토리 카드.

4. 정보 → 실행 시너지 (Premium)
- 스프링노트 어시스턴트 (리치 에디터 & 프리 캔버스):
  * 모던 WYSIWYG 에디터: 헤더, 표, 태스크 목록, 서식, 커스텀 폰트를 지원하는 Tiptap 기반 에디터.
  * 프리폼 인터랙티브 캔버스: 이미지, 커스텀 포스트잇 메모, 리치 북마크 카드를 노트에 드래그 앤 드롭으로 자유롭게 배치.
  * 부드러운 인라인 스크롤: 캔버스 요소가 리치 텍스트 콘텐츠와 함께 네이티브하고 인라인으로 60fps로 스크롤.
  * 어댑티브 컬러 테마 동기화: 라이트/그리드/세피아/다크 테마에 맞춰 노트 UI 스타일이 자동 전환. Chrome 시스템 테마와의 직접 동기화도 지원.

- 마인드맵 실행 허브 (비주얼 브레인스토밍):
  * 자동 레이아웃 엔진: 북마크 계층 구조와 폴더에서 시각적 마인드맵을 즉시 생성.
  * 맞춤 비주얼 커스터마이징: 노드 모양(팔각형 노드 포함), HSL 컬러, 연결선(두께, 선 스타일, 커스텀 색상)을 자유롭게 개인화.
  * 다기능 사이드바 패널: 슬라이드 아웃 사이드바에서 인라인 프라이빗 메모 편집. 오버레이 가이드로 키보드 단축키 확인 가능.
  * AI 주제 확장 & TODO 동기화: Gemini Nano로 주제를 확장하고, 마인드맵 노드 브랜치를 원클릭으로 캘린더 이벤트 또는 TODO 태스크로 변환.
- AI 메모 코파일럿 & 클리퍼: 웹 페이지의 텍스트를 드래그 선택만 해도, AI가 다국어 메모로 자동 정제·저장.

5. 파워 유저 스위트 (Premium)
- FTS 본문 검색: 북마크 저장 시 백그라운드에서 웹 페이지를 스크랩하여, 제목·URL·태그·요약·본문 전체에 대한 초고속 전문 검색 제공.
- 스마트 탭 서스펜더: 비활성 백그라운드 탭을 자동으로 일시 정지하여 RAM을 최대 90% 절약. 브라우저를 항상 빠른 상태로 유지합니다.
- 탭 그룹 양방향 동기화: 활성 Chrome 탭 그룹을 폴더로 저장하고, 네이티브 컬러 코드 Chrome 탭 그룹으로 즉시 복원.
- 개인정보 세션 파쇄기: '보안 폴더'를 지정하면 해당 탭을 닫는 즉시 쿠키, 스토리지, 방문 기록을 완전 자동 소거.
- 젠 리더 모드: 광고와 잡음을 제거한 깔끔한 독서 모드. 세피아/다크 테마와 동적 목차(TOC) 지원.
- 내장 광고 차단기: 번들로 제공되는 EasyList 기반 규칙셋으로 모든 사이트의 광고와 트래커를 차단합니다 (주기적으로 업데이트). 도메인별 예외 허용을 토글 하나로 설정 가능 — 모든 필터링은 declarativeNetRequest를 통해 브라우저 엔진 내에서 처리되므로, 확장 프로그램이 요청 데이터를 직접 읽지 않습니다.

🔒 프라이버시 & 성능 최우선
- 100% 로컬 저장: 모든 북마크 데이터, 전문 인덱스, AI 연산이 내 기기 로컬에서 실행됩니다 (chrome.storage.local). 개인 데이터는 기기 밖으로 나가지 않습니다.
- 사용자 데이터 수집 없음: ClickBook은 개인정보나 방문 기록을 외부 서버로 전송하지 않습니다. 일부 기능(광고 차단 규칙 업데이트, GitHub 트렌딩, 위키피디아 미리보기, Hacker News 피드)은 콘텐츠 표시 목적으로만 공개 API에 아웃바운드 요청을 보내며, 사용자 데이터는 포함되지 않습니다.

⚙️ 크롬 내장 AI (GEMINI NANO) 활성화 방법
Google Chrome(v127 이상)에서 로컬 AI 기능을 해제하는 설정:
1. chrome://flags/#optimization-guide-on-device-model 접속 → "Enabled (BypassPrefRequirement)" 선택.
2. chrome://flags/#prompt-api-for-gemini-nano 접속 → "Enabled" 선택.
3. Chrome 재시작. 브라우저가 자동으로 모델을 다운로드합니다.
(참고: Gemini Nano가 준비되지 않은 경우, 룰 기반 폴백 시스템이 분류와 태그 작업을 처리합니다.)
