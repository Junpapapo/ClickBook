常見問題與解答 (Q&A)

彙整使用 ClickBook 智慧生產力擴充功能時的常見疑問與完整解決方案。

Q 設為新分頁時，Chrome 彈出「是否復原為 Google？」提示，擴充功能無法自動關閉嗎？

沒錯，該安全提示視窗無法透過擴充功能程式碼強制控制或繞過。

此提示是 Chrome 瀏覽器為保護使用者免受惡意軟體（分頁劫持者）暗中竄改搜尋引擎或新分頁，而內建的瀏覽器原生硬編碼安全防護機制。

若要正常將 ClickBook 設為新分頁，請在安裝後首次開啟新分頁時，務必親自點擊 [保留變更 (Keep changes)] 按鈕。

Q 不小心按到了「復原設定」，導致新分頁或儀表板變成白畫面或無法開啟。

若不小心點擊了[復原設定]，Chrome 會單方面撤銷 ClickBook 的新分頁跳轉權限，導致內部設定與瀏覽器阻擋狀態不同步而出現空白。

只需按照以下簡單步驟重設瀏覽器安全權限即可立即修復：

最快且穩定的修復步驟：
  1. 於 Chrome 網址列輸入 chrome://extensions/ 進入擴充功能管理頁面。
  2. 找到 ClickBook 卡片，將右下角的藍色啟用開關關閉 (OFF) 後再次開啟 (ON)。
  3. 開啟一個空白新分頁，Chrome 將重新彈出安全提示視窗。
  4. 此時點擊 [保留變更 (Keep changes)]，即可瞬間恢復所有功能。
Q 匯入 Chrome 書籤或批次登錄時，一直卡在「登錄中...」狀態很慢。

此情況通常發生於使用者電腦尚未完全配置 Chrome 本機 AI (Gemini Nano) 環境時的會話等待延遲，已於最新版本中獲得全面最佳化解決。

ClickBook 在匯入時會以小於 1ms 的極速預先診斷 AI 可用性。若 AI 尚未就緒，將自動無縫切換至超高速規則比對分類器 (Fallback)，確保批次匯入順暢不卡頓。

書籤的 AI 摘要與詳細標籤會在背景執行緒中非同步慢慢生成，完全不影響儀表板的流暢操作。

Q 智慧分頁休眠 (Tab Suspender) 運作時，會把正在播放音樂或重要的分頁休眠嗎？ Premium

請完全放心。ClickBook 的智慧休眠演算法以保護使用者作業為最高優先。以下分頁絕對不會被強制休眠：

  • 音訊播放分頁： YouTube、Spotify 等背景正在播放音訊或影片的分頁。
  • 已固定分頁 (Pinned Tabs)： 瀏覽器左側固定的常駐工作分頁。
  • 目前使用中的分頁： 您正在瀏覽與操作的活動分頁。
  • 正在填寫表單的頁面： 偵測到表單輸入欄位的作業頁面。
Q 安全防護資料夾 (Secure Folder) 的自動銷毀器會清除哪些隱私痕跡？ Premium

將機密資料或金融網域設為安全資料夾後，瀏覽該網頁時工具列圖示會亮起綠色 `SEC` 徽章。關閉相關分頁的瞬間，僅針對該網域 (Origin) 的以下資料將徹底自動銷毀：

  • Cookie： 自動登入狀態與追蹤會話紀錄
  • 本機與工作階段儲存 (LocalStorage, SessionStorage)
  • 資料庫痕跡： IndexedDB、WebSQL
  • 網站快取與 Service Worker
  • 瀏覽記錄與暫存檔案
Q 如何將 Chrome 原生分頁群組與 ClickBook 資料夾雙向同步？ Premium

ClickBook 支援與 Chrome 分頁群組的完美雙向同步：

  • 將分頁群組儲存為 ClickBook 資料夾：點擊擴充功能彈出視窗，會列出當前開啟的分頁群組與顏色標記。選擇群組並點擊 [Save Group]，即可建立包含群組內所有分頁的新資料夾。
  • 將資料夾還原為 Chrome 分頁群組：於側邊欄資料夾點擊圖層按鈕，或於資料夾檢視頁面點擊 [Open as Chrome Tab Group]，即可依原有名稱與自訂顏色在 Chrome 分頁列上一鍵還原原生群組。
Q 如何將書籤資料轉移到新電腦或完整備份？

ClickBook 的所有資料均安全保存在您的電腦本機中 (Local-First)，並提供一鍵匯出匯入功能。

點擊儀表板右上角的設定齒輪圖示，前往資料管理分頁，點擊 [匯出完整備份 (JSON)] 即可下載包含階層結構、備忘與設定的 JSON 檔案。

在新電腦或新瀏覽器中點擊 [還原備份] 選擇該檔案，1 秒內即可無縫還原所有書籤與自訂圖示。

Q 全文檢索搜尋 (FTS) 與智慧剪輯功能有何特色？ Premium

智慧剪輯器 (Smart Clipper) 會在儲存書籤時於背景過濾廣告與無關排版，將純淨內文擷取至本機資料庫。

搭配 本機全文檢索 (FTS) 引擎：

  • 空格分隔多關鍵字搜尋： 輸入如 React 狀態管理，即可即時比對內文、標題、標籤與摘要。
  • 零延遲效能： 無需向任何外部伺服器發送請求，數千篇文章也能在 10ms 內極速呈現搜尋結果。
Q 離線閱讀模式 (Offline Reader) 與 Zen 沉浸閱讀器是什麼？ Premium

離線閱讀模式能將儲存的網頁內文轉換為無廣告、排版典雅的沉浸式數位書籍。

  • 典雅主題與字型： 支援減少眼睛疲勞的淺色、深色與羊皮紙主題，並提供 Serif、Sans、Mono 三種字型與字級縮放。
  • 智慧目錄 (TOC)： 自動解析標題結構產生左側懸浮大綱，點擊即可平滑捲動跳轉。
  • Markdown 快速匯出： 一鍵將乾淨文章複製為 Markdown 或純文字格式。
  • Zen Reader 支援： 除了書籤文章，便條板上的長篇筆記也可一鍵切換至 Zen Reader 進行專注閱讀。
Q AI 清理工具如何找出重複的書籤？

AI 清理工具會智慧掃描整座書籤資料庫，依據網址正規化與標題語意將高度相似的項目分組。

系統會自動建議保留最早建立的原始書籤。檢視分組後，點擊一鍵即可安全刪除重複項目，常保資料夾整潔。

Q ClickBook 夥伴 (Buddy) 與番茄鐘專注計時器如何運作？ Premium

ClickBook 夥伴是常駐於網頁角落的可愛動畫桌面寵物。點擊即可呼叫 9 大快捷圓形選單：

  • 翻譯： 反白選取網頁文字即可瞬間翻譯。
  • 書籤： 一鍵快速儲存當前頁面。
  • AI 對話： 開啟 Gemini Nano 聊天面板解答疑問。
  • 計時： 快速啟動番茄鐘專注計時。
  • 休息： 開啟全螢幕療癒視覺與白噪音放鬆模式。
  • 便條 & 待辦： 在頁面上貼上便利貼並管理今日檢查清單。
  • 隱藏與自訂： 細部自訂角色大小、透明度、時鐘顯示或在特定網域隱藏。

達成專注目標後可在夥伴圖鑑中解鎖新角色，並享受極光星空、靜謐森林等全螢幕慶祝視覺主題。

Q 心智圖 (Mind Map) 視覺化檢視有哪些實用功能？ Premium

互動式心智圖將您的書籤階層樹狀結構轉換為視覺化畫布：

  • 自由排版： 透過拖曳自由調整節點位置，座標會自動永久儲存。
  • 外觀自訂： 可自訂八角形等節點形狀、HSL 主題色彩與連線粗細樣式。
  • AI 發想與 TODO 轉換： 運用 Gemini Nano 延伸子主題，並可一鍵將節點轉換為行事曆行程或待辦任務。
  • 節點私密備忘： 透過側邊抽屜面板為每個節點撰寫詳細私密備忘。
Q 數位手帳筆記 (Spring Note) 與智慧行事曆如何聯動？ Premium

數位手帳筆記結合了 Tiptap 富文本排版與自由畫布，可自由拖放圖片、便利貼與書籤卡片，所有物件與內文以 60fps 流暢同步原生滾動。

智慧行事曆與手帳、待辦看板及便條深度整合。支援拖放調整排程、月/週/日視圖切換，並自動連動台、港、美、日等官方國定假日。
