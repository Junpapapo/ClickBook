> **一键保存标签页，让 AI 自动将其分类至文件夹中。**

ClickBook 是一款基于 Chrome Manifest V3 构建的书签管理工具。它可以让您只需点击一下即可立即保存当前标签页，并使用 Chrome 内置 AI (Gemini Nano) 或备用规则系统自动将其归类到适当的文件夹中。

## 屏幕截图

| 弹出窗口 | 管理仪表板 |
|---|---|
| 点击图标一键保存 | 在专用标签页中进行层级化管理 |

---

## 主要功能

| # | 功能 | 描述 |
|---|---|---|
| 1 | **一键保存** | 点击扩展图标即可立即保存当前标签页。 |
| 2 | **AI 自动分类** | 使用 Chrome Gemini Nano (`window.ai`) 分析网址与标题并归类至文件夹。 |
| 3 | **AI 批量整理** | 侧边栏一键按钮，可重新分类所有已保存的书签（具备自动备份功能）。 |
| 4 | **自动标签** | AI 会在后台自动为未标签的书签生成并保存标签。 |
| 5 | **任务控制中心** | 实时监控所有后台 AI 任务的进度条与状态。 |
| 6 | **AI 标签云** | 可折叠的交互式 HSL 标签云，支持筛选、合并与内联编辑标签。 |
| 7 | **层级化文件夹** | 支持无限层级嵌套、重命名、移动与设置 Emoji 图标。 |
| 8 | **拖放操作 (Drag & Drop)** | 直观地重新排列书签与文件夹。 |
| 9 | **模式快照** | 将整个文件夹与书签布局保存为快照并随时还原。 |
| 10 | **Chrome 同步** | 导入、导出并与原生 Chrome 书签同步。 |
| 11 | **视觉主题** | 支持深色与浅色模式（Dark/Light Mode）。 |
| 12 | **100% 离线** | 完全在本地使用 `chrome.storage.local` 运行（无需外部服务器）。 |
| 13 | **多语言支持** | 完整支持 7 种语言（英文、韩文、日文、德文、西班牙文、繁体中文、简体中文）。 |
| 14 | **AI 荧光笔剪藏 (Premium)** | 选取文本并通过右键菜单自动将其整理为多语言笔记。 |
| 15 | **智能标签页暂停 (Premium)** | 自动暂停后台不活跃标签页，最多可节省 90% RAM 内存。 |
| 16 | **标签页组同步 (Premium)** | 备份并还原 Chrome 原生标签页组至文件夹中。 |
| 17 | **隐私会话清除 (Premium)** | 关闭安全文件夹中的标签页时自动清除 Cookie 与缓存。 |
| 18 | **FTS 全文检索 (Premium)** | 支持实时对已保存网页的完整正文进行多关键字搜索。 |
| 19 | **离线阅读与 Zen 模式 (Premium)** | 无干扰阅读模式，配备主题、动态目录与滚动进度条。 |
| 20 | **AI 清理器** | 基于 AI 的重复项检测，轻松清理重复书签。 |
| 21 | **可视化思维导图 (Premium)** | 节点式交互思维导图视图，支持 AI 拓展节点与图标选择器。 |
| 22 | **趋势排行榜** | 内置 GitHub Trending、Hugging Face、Hacker News 及 Wikipedia 排行榜。 |
| 23 | **生产力看板** | 整合 Kanban 风格的 TODO 看板与备忘录管理系统。 |
| 24 | **智能日历整合 (Premium)** | 无缝整合 Todo/Memo 与多国节假日同步的智能日历。 |
| 25 | **复古弹簧笔记 (Premium)** | 基于 Tiptap 的富文本笔记空间，具备模拟书籍视觉主题。 |
| 26 | **ClickBook 桌面伙伴与专注计时器 (Premium)** | 互动式桌面宠物，配备番茄钟计时器与环形菜单。 |
| 27 | **智能声母搜索** | 超高速韩文声母搜索支持（例如 输入 'ㅋㄹㅂ' 搜索 'ClickBook'）。 |
